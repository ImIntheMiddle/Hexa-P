# Baselines

Re-implementations of the methods that Hexa-P is compared with.

- `social_transmotion.py`: Social-Transmotion (Saadatnejad et al., ICLR 2024) on SMPL-24 pose
  tokens with several path heads. It is derived from
  [Social-Transmotion](https://github.com/vita-epfl/social-transmotion) and is distributed under
  the GNU AGPL-3.0 (`LICENSE.social_transmotion`, the license file of Social-Transmotion).
- `emloco_mlp.py`: the plausibility estimator of EmLoco (Taketsugu et al., CVPR 2025). It is
  written by the authors of Hexa-P and is released under the Apache License 2.0 like `src/hexap/`.
